Layout generates a set of annotated exhibits showing how a component's auto-layout containers are configured — direction, alignment, resizing, padding, and item spacing — drawn as markers directly over a copy of the component's artwork. It's the section to check when you need to know exactly how much space is baked into a component, or how its containers stretch and align, without digging through Figma's own layout panel.

## What It Includes

- **Direction arrow** — shows whether a container lays out horizontally or vertically, including wrap
- **Alignment icon** — shows how children are aligned on both axes (e.g. "Top left", "Middle center", "Spaced equally")
- **Resizing markers** — separate vertical and horizontal markers showing whether a container is fixed, hugging, or filling
- **Padding markers** — a marker per side (top, bottom, start, end) with its value, only shown where padding is greater than zero
- **Item spacing markers** — markers between children showing the gap distributed along the axis
- **Layout Content list** — a text list pairing each annotated container with its direction, alignment, resizing, padding, and spacing values

## Related Settings

- **[Variant Depth](/specs/settings/variant-depth/)** — Controls how many per-variant layout subsections appear
- **[Details](/specs/settings/details/)** — `LAYERED` shows only changed values per variant; `FULL` repeats everything
- **[Collapse Primitive Wrapper](/specs/settings/collapse-primitive-wrapper/)** — Removes the wrapper container's own layout exhibit

## Examples

### Basic Layout

A component with one auto-layout container produces a single exhibit: the artwork annotated with a direction arrow, alignment icon, resizing markers, and padding/spacing markers, paired with a Layout Content entry listing the same values as text.

### Multiple Layout Containers and Variants

Components with nested auto-layout containers get one exhibit per container. When a variant changes layout-relevant properties on a container — different padding, alignment, or resizing — Specs adds a "Default" subsection alongside a subsection per affected variant, and each variant's exhibit annotates only the properties that changed rather than repeating everything already shown in Default.
