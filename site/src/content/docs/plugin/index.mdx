## No handoff tax

A designer finishes a component. An engineer needs to know exactly how it's built. Today that gap gets filled with screenshots, Slack threads, and re-explaining the same thing twice. The Specs Figma Plugin closes it: select the component, generate, and a complete visual spec appears next to it on the canvas — same file, same context, zero re-typing.

<CardGrid>
<Card title="Free, forever">

Anatomy, Props, Layout, Modes, Styling, and Data — every section that answers "how is this actually built" is free for every user, no subscription required.

</Card>
<Card title="Built for both audiences">

Designers get a visual, annotated breakdown they can read at a glance. Engineers and AI agents get the same information as structured data, ready to paste into a ticket, a prompt, or a pipeline.

</Card>
</CardGrid>
