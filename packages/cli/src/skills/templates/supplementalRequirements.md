# <Name> — supplemental requirements

Requirements this component needs that the spec cannot carry. Each entry is a testable statement of intent — it transfers directly to a test-case criterion. Low on rationale, high on intent. Every entry cites the schema path that cannot carry it and names where it is implemented.

Format per entry:

- **Intent** — one testable sentence of what must be true.
- **Schema gap** — the path that would carry it and why it cannot (`styles.schema.json#/definitions/…`).
- **Implemented in** — the hand-authored file(s), relative to the platform tree.
- **Regeneration risk** — what a re-emit or component rename would break; re-check after every regeneration.
